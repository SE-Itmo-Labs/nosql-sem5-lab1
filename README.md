Внимание! У разных вариантов разные параметры задания!
Вариант №689

Доработать приложение из лабораторной работы №1. Существующие CRUD API и key-value-хранилище должны продолжать работать.

Добавить MongoDB для постоянного хранения основных объектов.
Дополнительные параметры

- вложенные данные: журнал действий;
- связанная коллекция: правила обработки;
- индексируемый запрос: поиск по связанной сущности и дате изменения;
- аналитический запрос: наиболее часто используемые метки;
- изменение структуры: преобразование одиночной метки в массив меток.

Требования к программе

+ Перенести основные объекты в назначенную документоориентированную систему, сохранив CRUD API первой лабораторной.
+ Реализовать назначенные вложенные данные и связанную коллекцию.
+ Добавить фильтрацию, сортировку, пагинацию и поиск по вложенным полям.
+ Транзакционно изменять связанную сущность и одновременно обновлять вложенные данные.
- Построить aggregation pipeline для назначенного аналитического запроса.
- Создать составной индекс и сравнить выполнение запроса через explain.
- Настроить JSON Schema Validation и выполнить повторяемую миграцию существующих документов.
- Сохранить key-value-хранилище первой лабораторной и использовать его для кэширования запроса к назначенной системе с TTL и инвалидацией.


## Быстрый запуск

```bash
cp credentials.env.example credentials.env
# Для локальных тестовых пользователей и афиши при необходимости задайте:
# APP_DATA_INITIALIZER_ENABLED=true
./gradlew clean build
docker compose --env-file credentials.env up -d --build
```

## Проверить MongoDB

```bash
docker compose --env-file credentials.env exec mongodb mongosh somedb_mongo
```

После запуска:

- API: <http://localhost:16767>
- Swagger UI: <http://localhost:16767/swagger-ui/index.html>
- OpenAPI JSON: <http://localhost:16767/v3/api-docs>

Тестовые пользователи создаются только при
`APP_DATA_INITIALIZER_ENABLED=true`:

- `user` / `12345`;
- `admin` / `12345`.
